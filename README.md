# DAYFORGE

DAYFORGE is a personal planning application with a weekly task calendar and a milestone calendar. The overall scope and current task status are in [the project task plan](docs/tasks/README.md).

## Start local development

Follow the [Windows development setup](docs/development.md) to install the pinned tools, create local configuration, start MySQL and run the Next.js and FastAPI development servers.
